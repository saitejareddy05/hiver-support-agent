Place the Kaggle Customer Support on Twitter CSV here as `twcs.csv`.

Download from https://www.kaggle.com/datasets/thoughtvector/customer-support-on-twitter
using the Kaggle UI or API. The pipeline accepts the common columns `tweet_id`,
`author_id`, `inbound`, `created_at`, `text`, `response_tweet_id`, and
`in_response_to_tweet_id`.
